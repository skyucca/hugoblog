# hugoblog
hugo based blog
## 新建文章步骤
- 进入hugoblog/posts/目录；
- 找到“+”符号，点击“Create New File”；
- 在文件名处输入文件名（最好不要以标点符号结尾）；
- 在正文前首先输入以下内容：
  - 三条短线
  - title: "这里是标题"
  - date: 20✕✕-✕✕-✕✕
  - draft: false
  - 三条短线
- 然后在下方输入Markdown格式的博客正文
- 输入完成后，Preview预览，确定推送了，点击右上角“Commit changes”，再点一次“Commit changes”即可。
